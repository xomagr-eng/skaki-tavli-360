# Σκάκι & Τάβλι 360°

Offline εφαρμογή εκπαίδευσης **Σκάκι** και **Τάβλι** (Πόρτες, Πλακωτό, Φεύγα, Ασσόδυο).

## Χαρακτηριστικά
- ♟️ **Σκάκι**: διαδραστική σκακιέρα με πλήρεις κανόνες + AI αντίπαλο, Staunton 3D πιόνια, drag-and-drop, ανοίγματα, 12 ασκήσεις τακτικής, φινάλε, στρατηγική.
- 🎲 **Τάβλι**: Πόρτες / Πλακωτό / Φεύγα / **Ασσόδυο** (με πλήρη κανόνα 1-2), AI αντίπαλο, ρεαλιστική ξύλινη ταβλιέρα, ζάρια με ήχο & πτώση, drag-and-drop, highlight νόμιμων κινήσεων & μαζέματος, live pip count, doubling cube trainer.
- 🎨 Πολλά θέματα/χρώματα (ταβλιέρα, πιόνια, πούλια), 3D όψη, ήχοι — **100% offline**.
- 🎯 Πλάνο ανέλιξης (roadmap) με αποθήκευση προόδου, γλωσσάρι.

## Χρήση
Άνοιξε το `index.html` σε οποιονδήποτε browser (PC / smartphone / tablet). Δεν χρειάζεται εγκατάσταση ή σύνδεση.

Live: μέσω GitHub Pages.
